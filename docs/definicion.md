https://mimandadito.com es un sitio web que se dedica a la comercializacion de los productos liquidos de GEPP , me gusta para mi emprendimiento de postre-cito https://postrecito.axiacorehub.com, ayudame a realizar una app web para que el funcionamiento se equipare pero lo productos sean los de mi postrecito.

Hazla bajo filamentphp. Usa laravel 13 y coloca un chatbot con RAG sobre el catalogo de productos y servicio y realiza pedidos con el chatbot. usa el sdk ai para RAG de laravel. No uses agentes en el rag, usa solo embedding y retrieval. usa la api de gemini, lista para ponerla desde .env

Que se muestren los productos como en https://mimandadito.com, pero con los productos de postrecito. y que un usuario pueda ver el catalogo y realizar pedidos. Pueden ver el catalogo sin loguearse pero sera necesario loguearse para realizar pedidos.
